### Christian Social Site

## About and Purpose

This is going to be a simple social media sites for Christians and anyone alike. I was going to remake another Social Media site I made a long time ago, and then had the God-given thought to scrap it and start this.

## Specifications
The website will be hosted on a server with the following specs:

* Ubuntu 22.04
* Apache 2.0
* Php 8.3
* MySql

Using the following languages as well:
* HTML 5
* CSS (With Bootstrap)
* JavaScript

## Preview and Joining
Once a week, this will be pulled, reivewed, and then published with the updates to the main website at [Christian Social Site.](https://css.logandag.dev) Updates and security support and updates will be on the "Security Tab" of the GitHub.
